Arsitektur Sistem Murni API (Tanpa Chatwoot)

100% Direct REST API

Pesan WhatsApp dari pengguna diteruskan langsung oleh gateway OpenKoneksi.com ke Developer Backend kita melalui Webhook payload JSON. Chatwoot telah dieliminasi sepenuhnya untuk menghemat RAM VPS & latensi.

1. WhatsApp User 📲 Kirim Pesan / Klik Menu
⬇️
2. OpenKoneksi.com (WABA) 🌐 Inbound Webhook (POST JSON)
⬇️
3. SapaTamu Backend (Node.js) ⚙️ AI Gemini + State Machine + SQLite
⬇️
4. OpenKoneksi Outbound API 🚀 REST POST /v1/messages
⬇️
5. WhatsApp User App ✅ Terima Balasan Cerdas / Invoice
Server Memory: ~50 MB RAM (Hemat vs 4GB Chatwoot) Ready for Production
